Pasar Malam: Warung Saji — game memasak cepat di warung pasar malam Indonesia. Pesanan masuk di papan tiket: ambil bahan dari bin, masak di wok berapi (jangan sampai hangus), potong di talenan, susun di piring, lalu bunyikan lonceng dan sajikan sebelum pelanggan pergi. Koki Budi berjalan keliling dapur (WASD atau klik), 6 resep Indonesia (Nasi Goreng, Mie Goreng, Ayam Geprek, Nasi Ayam, Mie Ayam, Omelet Sayur), 3 gelombang makin ramai (MULAI → JAM RAMAI → PUNCAK), streak/kombo sampai x2, dan target pendapatan Rp 150.000 dalam shift 2:30. Makanan digambar mengkilap dengan gradient dan sparkle, pelanggan berwajah dengan mood yang berubahตาม kesabaran, suara disintesis WebAudio — semua orisinil, tanpa aset salinan. Keyboard + mouse, offline, tanpa build step.

## Cara main

- Klik bin bahan untuk mengambil, klik wok untuk memasak, klik talenan untuk memotong, klik piring untuk menyusun, klik lonceng PASS untuk menyajikan.
- A/D atau ←/→ untuk jalan, E untuk beraksi di stasiun terdekat, P jeda, M suara, ENTER mulai / main lagi.
- Piring lengkap yang cocok dengan tiket = lonceng menyala "SAJIKAN!". Layani cepat beruntun untuk streak dan bonus.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 — atau buka game/index.html langsung di desktop Chrome.
